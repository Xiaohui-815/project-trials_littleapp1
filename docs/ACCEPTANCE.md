# 验收记录

## 已完成的本地验证

- TypeScript 检查与 Vite 生产构建。
- 14 项单元测试：小数精度、北京时间跨年、闰日与日期验证、统计补零、未登录拒绝、两账号隔离、请求身份伪造、并发重复提交、跨分页汇总、跨年编辑与删除、版本冲突、错误信息处理和托管登录地址验证。
- 8 项 Edge 浏览器测试：未配置状态、新增／输入校验／编辑／取消删除／确认删除、月份年份筛选、哈希路由刷新、键盘关闭与焦点恢复、退出后清理数据、保存失败保留输入并重试。
- 1280、1440、1920 像素桌面宽度和 390 像素手机宽度无整页横向溢出；查看了截图。

浏览器交互测试使用本地开发模式的内存示例数据；权限测试使用独立的两个身份和内存数据库替身。**这些测试证明业务规则与页面行为，不证明真实 CloudBase 环境已经联通。**

## 需要 CloudBase 环境后执行

- [ ] 使用两个不同邮箱完成注册、验证、密码登录及退出。
- [ ] 在托管认证页完成密码重置，确认新密码能登录。
- [ ] 验证从 GitHub Pages 跳转至托管页后，能够回到仓库子路径并建立有效会话。
- [ ] 账号 A 录入 0.10 和 0.20，统计显示 0.30。
- [ ] 账号 B 列表及统计不包含 A 的记录；使用 A 的记录编号调用编辑与删除接口被拒绝。
- [ ] 匿名或已退出用户调用任一云函数操作被拒绝；客户端直接读写集合被规则拒绝。
- [ ] 录入超过一页的明细，验证总计完整。
- [ ] 补录历史月份，跨月／跨年修改，再删除，所有汇总正确更新。
- [ ] 刷新、更换浏览器及另一台设备登录同一账号，记录仍然存在。
- [ ] 模拟断网：保存失败保留输入；恢复网络重试不会重复记账。
- [ ] 两个页面编辑同一记录时，旧版本不能覆盖新版本。
- [ ] 在测试人员实际中国大陆网络验证 Pages、认证跳转、邮件收取、数据库读写。

## 当前限制

- CloudBase 环境尚未创建，以上真实接入验收项未执行。
- 尚未购买域名或配置生产部署，属于个人小范围测试项目。
- Node SDK 最新版本的文档数据库依赖仍引入 `lodash.set` / `lodash.unset` 的已知上游审计项；本应用不接受用户提供的字段路径或查询对象，写入字段均由服务端白名单构造。Axios 已单独覆盖至修复版本 0.34.0；正式开放前应再次核查上游补丁，不使用 `npm audit fix --force` 降级 SDK。
